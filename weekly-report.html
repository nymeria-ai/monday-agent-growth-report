🧪 LLM-vs-LLM Testing Protocol 🟡 Planned - UK Launch

Since ChatGPT's ad matching is LLM-based (semantic, not keyword), we use our own LLM to reverse-engineer how hints are interpreted - one LLM "speaking the language" of another's matching logic.

8 Testing Dimensions

  • 1️⃣ Abstraction Level: Literal ("PM software") vs abstract ("my team is drowning in chaos")
  • 2️⃣ Conversational Framing: Formal vs question vs first-person problem
  • 3️⃣ Intent Stage: Unaware → Problem-aware → Solution-aware → Decision-stage
  • 4️⃣ Emotional vs Rational: Frustration/urgency vs feature comparison
  • 5️⃣ Specificity Stacking: Single to 4-dimension hyper-targeted hints
  • 6️⃣ Negative Space: "Moving away from" hints ("tired of Jira complexity")
  • 7️⃣ Persona-Based: Describe the user, not the product
  • 8️⃣ Prompt-Engineering: Chain-of-thought, role-play, structured hints

Execution Plan

  • 🎯 Campaign: uk-en-test-context-hints-lab
  • 📊 8 ad groups (1 per dimension), 4-5 hints each
  • 🧪 Controlled: identical ads, same bid ($5 CPC), same LP, GB-only
  • 📅 Phase 1 (Week 1): Baseline - measure reach, CTR, CPC per type
  • 📈 Phase 2 (Week 2-3): Deep-dive top 3 dimensions
  • 🚀 Phase 3: Scale winners into production campaigns
